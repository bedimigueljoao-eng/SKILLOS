# SKILLOS

PWA offline para estruturar, praticar, comprovar e acompanhar competências.

## Publicar no GitHub Pages
1. Crie um repositório público.
2. Envie todos os ficheiros desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Escolha **Deploy from a branch**, ramo **main**, pasta **/(root)**.
5. Guarde e aguarde a publicação.

## Principais funções
- Cadastro de competências e níveis
- Diagnóstico inicial
- Sugestões automáticas para Comunicação, Excel e Liderança
- Sub-habilidades, conteúdos, atividades e critérios de comprovação
- Evidências, avaliações e progresso
- Cronómetro contínuo com pausa e gravação
- Backup, restauração e eliminação total dos dados
- Instalação PWA e funcionamento offline

Os dados são guardados localmente no navegador. Exporte backups regularmente.
